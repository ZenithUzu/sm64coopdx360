# Red de la base Claude v44

Esta publicación conserva el comportamiento de red de la iteración 44. No cambia puertos ni introduce un identificador exclusivo de Xbox.

- Conexión directa: puerto predeterminado 7777.
- CoopNet: puerto predeterminado 34197.
- `coopnet_ip`: dirección del servicio CoopNet.
- `xbox_server_ip`: dirección opcional de un servidor privado; no es un nombre de salas.
- `xbox_host_on_xbox_server`: permite alojar en ese servidor privado.
- En el servicio público las salas sin contraseña usan `sm64coop-android`; las salas privadas o de servidores locales conservan el nombre PC de esta base. La aceptación de conexiones por el servicio oficial depende de su servidor.

No publicar archivos de configuración personales ni contraseñas de salas. La rama de calidad gráfica debe mantenerse separada de esta base.
