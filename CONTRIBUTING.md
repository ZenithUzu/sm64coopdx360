# Contribuir

- Revisa `docs/xbox360/STATUS.md` y distingue pruebas de compilación y de hardware.
- No subas ROMs, assets, binarios, SDKs, dumps, claves, logs privados ni archivos de configuración personal.
- No cambies avisos/licencias de terceros ni asumas que el código heredado está cubierto por MIT.
- Adjunta pasos reproducibles y datos de rendimiento comparables. Elimina nombres/rutas/IPs personales de logs.
- Ejecuta `python tools/verify_public_tree.py`, las pruebas anfitrión y el build PowerPC que corresponda. No presentes como probado un cambio de GPU que solo compiló.
- Mantén partidas/configuración fuera del repositorio. No incluyas artefactos completos del juego en GitHub Actions ni Releases.
